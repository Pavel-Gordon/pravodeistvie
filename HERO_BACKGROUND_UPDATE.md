# Обновление Hero-секции: фоновое изображение с оверлеем

## 📋 Выполненные изменения

### Задача
Заменить текущий фон Hero-секции на фоновое изображение с полупрозрачным тёмным оверлеем для улучшения визуального восприятия.

### Что было сделано

#### 1. Добавлено фоновое изображение
- **Источник:** Unsplash (профессиональное фото юридической тематики)
- **URL:** https://images.unsplash.com/photo-1589829545856-d10d557cf95f?w=1920&q=80
- **Разрешение:** 1920px ширина, качество 80%
- **Позиционирование:** `object-cover object-center` для полного покрытия секции

#### 2. Добавлены оверлеи для читаемости текста

**Основной градиентный оверлей:**
```css
bg-gradient-to-r from-[#0F172A]/95 via-[#0F172A]/80 to-[#0F172A]/60
```
- Слева: 95% непрозрачности (максимальная защита текста)
- Центр: 80% непрозрачности (баланс)
- Справа: 60% непрозрачности (лёгкое затемнение)

**Вертикальный градиент для глубины:**
```css
bg-gradient-to-b from-[#0F172A]/40 via-transparent to-[#0F172A]/60
```
- Сверху: 40% затемнение
- Центр: прозрачный
- Снизу: 60% затемнение

#### 3. Декоративные элементы
Сохранены декоративные круги в правом верхнем углу:
- Большой круг: 96x96 (384px), граница #C5A059/10
- Малый круг: 72x72 (288px), граница #C5A059/5
- Позиционирование: `pointer-events-none` (не блокируют клики)

### Структура HTML

```html
<section class="relative min-h-screen flex items-center overflow-hidden">
  <!-- Фоновое изображение -->
  <div class="absolute inset-0 z-0">
    <img 
      src="https://images.unsplash.com/photo-1589829545856-d10d557cf95f?w=1920&q=80" 
      alt="" 
      class="w-full h-full object-cover object-center"
    />
    <!-- Полупрозрачный тёмный оверлей -->
    <div class="absolute inset-0 bg-gradient-to-r from-[#0F172A]/95 via-[#0F172A]/80 to-[#0F172A]/60"></div>
    <!-- Дополнительное затемнение сверху и снизу для глубины -->
    <div class="absolute inset-0 bg-gradient-to-b from-[#0F172A]/40 via-transparent to-[#0F172A]/60"></div>
  </div>
  
  <!-- Декоративные круги справа -->
  <div class="absolute top-20 right-20 w-96 h-96 border border-[#C5A059]/10 rounded-full pointer-events-none"></div>
  <div class="absolute top-32 right-32 w-72 h-72 border border-[#C5A059]/5 rounded-full pointer-events-none"></div>
  
  <!-- Контент поверх фона -->
  <div class="relative z-10 max-w-7xl mx-auto px-6 lg:px-12 py-32 lg:py-0 w-full">
    <!-- существующий контент -->
  </div>
</section>
```

### Визуальные улучшения

#### До:
- Однотонный градиентный фон
- Плоский дизайн без глубины
- Декоративные круги с opacity 5%

#### После:
- Профессиональное фоновое изображение
- Многослойные градиенты для глубины
- Улучшенная читаемость текста
- Декоративные круги с opacity 10% и 5%
- Более динамичный и премиальный вид

### Технические детали

**Z-index структура:**
- `z-0`: фоновое изображение и оверлеи
- `z-10`: контент (текст, кнопки)
- Декоративные круги: без z-index (между фоном и контентом)

**Производительность:**
- Изображение загружается с параметрами оптимизации Unsplash
- `object-cover` обеспечивает адаптивность
- `pointer-events-none` на декоративных элементах
