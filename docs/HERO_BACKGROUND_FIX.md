# Исправление отображения фонового изображения в Hero-секции

## Проблема
Фоновое изображение не отображалось из-за слишком плотных оверлеев (95%, 80%, 60% прозрачности), которые полностью скрывали изображение.

## Решение

### 1. Упрощение структуры
- Убрал лишние градиенты
- Оставил один простой оверлей

### 2. Настройка прозрачности
**Было:**
```jsx
<div className="absolute inset-0 bg-gradient-to-r from-[#0F172A]/95 via-[#0F172A]/80 to-[#0F172A]/60"></div>
<div className="absolute inset-0 bg-gradient-to-b from-[#0F172A]/40 via-transparent to-[#0F172A]/60"></div>
```

**Стало:**
```jsx
<div className="absolute inset-0 bg-[#0F172A]/50" style={{ zIndex: 1 }}></div>
```

### 3. Правильная настройка z-index
```jsx
// Фон с изображением
<div className="absolute inset-0" style={{ zIndex: 0 }}>
  <img src="..." className="w-full h-full object-cover" loading="eager" />
</div>

// Полупрозрачный оверлей (50%)
<div className="absolute inset-0 bg-[#0F172A]/50" style={{ zIndex: 1 }}></div>

// Декоративные элементы
<div style={{ zIndex: 2 }}></div>

// Контент
<div style={{ zIndex: 10 }}></div>
```

### 4. Приоритетная загрузка
Добавлен атрибут `loading="eager"` для изображения, чтобы оно загружалось сразу.

## Результат
✅ Фоновое изображение теперь хорошо видно через полупрозрачный оверлей
✅ Текст остаётся читаемым благодаря 50% затемнению
✅ Правильная иерархия слоёв через z-index
✅ Проект успешно собран
